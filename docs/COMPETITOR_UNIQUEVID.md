# Разбор конкурента: @uniquevidbot («Уникализатор видео UniqueVid»)

Дата разбора: 2026-11-08. Аудитория ~37 тыс. пользователей. Веб-версия на reuploadvid.com
(вход через Telegram, на момент разбора виджет отдаёт «Bot domain invalid»). Публичный API
`https://reuploadvid.com/v1`, Bearer-токен, `/v1/me` без токена → 401 JSON.

## Продукт

- Вход по /start требует подписки на канал.
- Команды: `/menu`, `/support`, `/balance`. Меню: Уникализировать, Баланс, Купить кредиты,
  Пригласить друга, Настройки (язык, режим, число копий, API-ключ), Как пользоваться.
- Режимы: Base 720p, HD 1080p, HD+ 1080p (видимые изменения, заявлена проходимость >80 %).
- Копий: 1 / 5 / 10. Base: 3 / 5 / 10 кредитов.
- Пакеты: 200 кр — 500 ⭐, 500 — 1100 ⭐, 1000 — 1800 ⭐. Tribute ₽ / $, Stars.
- Кредиты живут 30 дней с последней покупки, при докупке старые сохраняются.
- Рефералка: +30 кредитов обоим.
- Лимит файла 150 МБ. 5 копий 8-секундного 720p — ~20 секунд с очередью.

## Что делает с видео (режим Base, 5 копий тестового ролика)

Исходник: 8 с, 1280×720, 30 fps, H.264 High CRF 20, 4.16 Мбит/с, AAC 48 кГц моно, тон 440 Гц,
теги title/artist/comment, x264 SEI.

### Метаданные
Все пользовательские теги удалены, x264 SEI вырезан, `encoder` → «H.264». Вписаны фейковые
профили устройств/софта с датой, поясом и GPS; имя файла подделано:

Слабость: у всех копий остались ffmpeg-овские `major_brand=isom`, `minor_version=512`,
`compatible_brands=isomiso2avc1mp41`, чего у реального iPhone не бывает. Apple handler_name
«Core Media Video» проставлен, но контейнер выдаёт FFmpeg.

### Геометрия
Зум + обрезка до нечётных разрешений: 1196×666, 1212×672, 1226×688, 1232×690, 1212×678.
У копий 2 и 4 — чёрные поля 8–22 px и неквадратный SAR (196061:196134, 207929:207946).
Зеркалирования нет (SSIM к оригиналу 0.79, к отражённому 0.48).

### Время
Длительность 7.54 / 8.50 / 7.81 / 7.57 / 8.05 с; fps 30.13 / 29 / 28 / 30.13 / 30;
кадров 226 / 232 / 218 / 227 / 240 (исходно 240). Скорость ±1–6 %.

### Звук
Растянут вместе с видео без сохранения тона: 440 Гц → 460 / 447 / 423 / 431 / 431 Гц.
Средняя громкость не тронута (−21.1 dB), пик вырос с −16.3 до −11.4…−15.5 dB (EQ/щелчки).
AAC 48 кГц моно сохранён.

### Цвет
Яркость ±3–5 уровней, насыщенность от −13 % до +8 %, оттенок на несколько градусов.
Шум не добавлен (плоские области без дисперсии).

### Кодек
Битрейт 4.16 → 2.1–2.5 Мбит/с, файл 4.3 → 2.3–2.6 МБ. Одна GOP на весь ролик (1 keyframe
вместо 4). High / yuv420p / level 3.1 сохранены.

### Чего нет
Водяных знаков, оверлеев, зеркала, шума, смены кодека.

## Целевые метрики для нашего выхода

Воспроизвести всё перечисленное одним проходом FFmpeg и превзойти по трём пунктам:
1. корректные бренды контейнера под профиль (exiftool для Apple-атомов);
2. сохранение тона при изменении темпа (`rubberband` / `atempo` без `asetrate`) как опция;
3. измеримая дистанция pHash / Chromaprint до оригинала вместо декларативных «80 %».
